Long-term records

In the Firebase version, this screen can also provide date-range exports, fiscal-year summaries, machine lifetime-cost reports, and an actual multi-sheet .xlsx workbook. The data model in this prototype is already structured for that.

Prototype storage

This version uses localStorage, which makes it safe to test without accounts, hosting costs, or a backend. Data exists only in this browser.

Production path

  1. Approve/refine this workflow and UI.
  2. Replace localStorage with Firestore.
  3. Add authenticated staff/admin access.
  4. Add secure email notification function.
  5. Generate permanent machine QR codes.
  6. Add Bemidji State / TAD branding.

Notification policy

Stakeholders are attached to machines, not hard-coded into a flow. Change the responsible people once and future reports use the new routing automatically.
