# Branded Merge Notes — v1.2

This release uses the uploaded `TAD-Lab-Manager-Prototype-v1.1` as the visual/layout baseline and the Spark build as the Firebase/data baseline.

## Restored visual structure
- branded TAD home page and hero
- supplied TAD logos and multi-color stripe
- yellow Cost Estimator / blue Machines & Maintenance / red Tutorials module system
- Quick Access cards
- Featured Machines
- 40-machine directory with lab-location color coding
- separate Cost Estimator, Machines & Maintenance, Tutorials, and permanent machine pages
- mobile-responsive behavior

## Spark functionality retained
- Firestore shared machine/report/repair records
- anonymous student reporting
- Microsoft 365 staff sign-in
- Firestore Security Rules
- App Check configuration path
- report status workflow
- repairs, costs, labor, and downtime
- CSV exports and JSON backup
- machine-specific maintenance URLs for Linktrees
- no Cloud Functions or automatic email in this release

## Tutorial integration
- 235 approved direct tutorials
- machine/category filtering
- direct tutorial links on the Tutorials page
- relevant direct tutorials on machine pages and maintenance reporting
- `Kinetic sculpture` mapped to ShopBot CNC Router
