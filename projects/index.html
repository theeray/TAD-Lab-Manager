TAD Project Cost Estimator

Student project budgeting and real-world cost simulation.

Student budgeting tool: use this estimator to plan project costs and practice real-world pricing considerations. This is not a public project-ordering system. Internal exception workflows can be handled separately by authorized TAD staff.
Demo pricing: the original workbook imports its master price table from another Google Sheet, so the rates in this version are test values. Update them under Pricing before using totals operationally.
Student estimates are private to this browser. Shared pricing and machine data are read-only for students; shared administrative data is protected separately through Firebase.
